Tako Grid

tako 文档站

tako 是多租户 Agent 运行时与 AI 工作台。你给它一个目标，它能读写项目、执行命令、搜索资料、 委派子代理，把长工作拆成可恢复的 Task，最后交付一份能打开检查的文件。

结构

架构总览

前端、接入层、run worker、长任务、结果发布、模型、扩展与存储——约 20 个责任节点。

 单场

run 生命周期

从 POST /api/runs 到定稿、记忆与显式续跑；九种帧、runlog／模型输入／journal 的分工。

 长任务

长任务与多 Agent 编排

持久 Task、依赖调度、结果发布、后台 bash、通知恢复、同组修订与继任组。

 存储

数据、状态与存储

PostgreSQL 当前模型、四类 Redis 临时状态、项目 content／runtime、会话 wire 与记忆双模式。
