# ═══ 用例 9：变更事件流（doc/46）——SSE 挂读 + Last-Event-ID 续传 ═══
# 端点 GET /api/events（SSE，帧面不进信封——doc/40 §6 的同款裁决）。帧两条行：
#   id: <seq>                                    ← stream entry id，续传游标
#   data: {"seq":"<seq>","type":"<type>","id":"<sid|wid>","at":"<RFC3339>"}
# type 词表：session_deleted / workspace_deleted / workspace_renamed（只通知、不带状态，
# 客户端收到后失效本地并永远跟一次重拉——doc/46 §3.1）。
# 游标语义：不带 Last-Event-ID = 从 `$` 挂起只推新事件（不回放历史）；带了 = 从它之后续读。
