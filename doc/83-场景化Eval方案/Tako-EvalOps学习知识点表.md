> 性质：学习辅助清单，不是施工契约；配套阅读为 [企业级 Agent 课程对 Tako 的借鉴分析](DataAgent课程借鉴与Tako落地分析.md)。已按完整十篇课程扩充，不再只覆盖 Eval 五章。
> 日期：2026-11-16。
> 评分口径：**对 Tako 的有用程度**按当前 Agent Runtime 与场景 Eval 的需要评 1～5 分，5 分最值得优先掌握；分数不表示该项是否缺失。
> 功能口径：✅＝已有对应能力；🔶＝只有部分、相关机制或只在公开基准中实现；⬜＝尚未具备；—＝模型原理、学习方法或非功能项。已有 Runtime 功能不等于已有自动 Eval。

## 建议的填写方式

User 一栏不只是标记“见过名词”，最好按能否实际操作填写：

- **不知道**：第一次看到；
- **听说过**：知道大概用途，但不能定义输入和输出；
- **能解释**：能举出 Tako 的一个真实例子，并说明没有它会出什么问题；
- **能实操**：能写出一个 Case／Grader／对照实验，或指出现有实现与验收证据。
