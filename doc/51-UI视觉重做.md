## 0. 病灶：在真屏幕上，这套界面有四个具体失败

2026-10-24 用 Playwright 无头跑 1440×900 与 390×844 两档实拍（图在 `/tmp/tako-ui/`，不入库），不是凭印象：

1. **侧栏底部压住内容**（1440×900）。`.rail` 是 flex 列、`.recent` 有 `min-height: 0` 但树内容 `overflow: visible`，`.rail-foot` 又是 `margin-top: auto`。10 条会话 + 3 个项目行超过可用高度后，树继续往下画，用户卡片和「退出」直接盖在「验收项目」和「展示更多」上——最下面那行会话点不到。
2. **手机端聊天被挤成一条**（390×844）。≤860px 时 `.rail` 变成三行 grid，**整棵项目树留在顶栏里**，占掉约 560px；聊天正文只剩底部约 120px，输入框贴底。打开会话要先看过半屏的目录。
3. **没有层级与比例**。同一页里：页面标题 24.8px/620、卡片标题 14px、正文 15px、侧栏会话 12.8px、按钮 12.8px；圆角同时存在 999 / 22 / 18 / 14 / 10 / 5px 六种；阴影里外混用；卡片是暖白贴米底，几乎看不出边界。
4. **对话像两块贴纸**。用户气泡 474px 宽、助手气泡 232px 宽，宽度全由内容决定、左右跳动；用量与「复制」是 12px 灰字塞在气泡底部，读起来像脚注；助手气泡的表格/代码块没有统一的内边距。

第 1、2 条是**功能伤**（点不到 / 没法用），第 3、4 条是**观感伤**。先修功能伤再统一观感。

## 1. 拍板（2026-10-24）

| 项 | 取值 |
|---|---|
| 视觉方向 | **中性现代风**：浅灰白底、白色卡片、1px 细边、单一蓝色强调色；去掉米色与暖阴影 |
| 手机 ≤860px | **抽屉式**：顶栏只留 品牌 / 新对话 / 菜单；导航 + 项目树 + 账户进左侧抽屉；聊天占满屏 |

## 2. 为什么先做 Token 层

现在颜色和尺寸是散着写的：8 个组件里 **150 处**硬编码颜色（App.vue 99、Configure.vue 16、ProjectsView.vue 12、MembersView.vue 8、ConfirmDialog.vue 6、InviteLanding.vue 5、PlanDoc.vue 3、PendingInvites.vue 1），还有 `#f6f1e7`、`#8fbfb0`、`rgba(15,110,86,.1)` 这类直接写死的值。**方向一换，逐页找颜色改**必然漏，而且下次再换还来一遍。所以第一拍只做一件事：把颜色/字阶/间距/圆角/阴影收进 `base.css` 的变量，组件里换成变量引用；视觉变化先只在 token 层生效，结构不动。

## 3. Token 取值（落 `web/src/base.css`）

```css
--bg: #f6f7f9;          /* 页面底：冷灰白 */
--bg-raised: #ffffff;   /* 卡片/气泡 */
--sidebar: #fbfbfc;     /* 侧栏：比页面略亮 */
--ink: #14161a;         /* 主文字 */
--ink-soft: #3d434d;    /* 次要文字 */
--muted: #6b7280;       /* 说明/时间 */
--line: #e6e8ec;
--line-strong: #d3d7de;
--accent: #2f6feb;      /* 单一强调色 */
--accent-ink: #1d4ed8;
--accent-soft: #eaf1fe;
--danger: #d92d20;  --danger-soft: #fef3f2;
--warn: #b54708;    --warn-soft: #fffaeb;
--shadow: 0 1px 2px rgba(16,17,20,.05), 0 12px 32px rgba(16,17,20,.08);
--radius: 12px;
```

字阶与间距（同样进 `:root`）：

| 名称 | 值 | 用在哪 |
|---|---|---|
| `--text-xs` | 12px | 时间、kicker、徽标 |
| `--text-sm` | 13px | 按钮、侧栏、次要说明 |
| `--text-base` | 14px | 卡片正文、表单 |
| `--text-md` | 15px | 对话正文 |
| `--text-lg` | 17px | 卡片标题、区块标题 |
| `--text-xl` | 22px | 页面标题 |
| `--space-1..6` | 4 / 8 / 12 / 16 / 24 / 32px | 全站间距 |

圆角只有三档：**8px（控件）/ 12px（卡片、气泡）/ 16px（面板、抽屉）**；999px 只给状态徽标与 chip。

## 4. 侧栏：三段式（修病灶 1）

- 结构：`.rail` = `head`（品牌 + 新对话 + 导航，不滚）+ `tree`（项目树，唯一可伸缩/可滚的一段）+ `foot`（账户，钉底、带 `border-top`）。
- `.recent` 从 flex 子项改成「可缩小 + `overflow` 收在自己身上」；树的滚动**只在视口真的装不下时出现**，不再设 `max-height`。900px 高、10 条会话、3 个项目的目标是**完全不出现滚动条**（下面 §6 有验收命令）。
- 会话行改**单行**：标题左、时间右（12px `--muted`），行高 30px，原来标题/时间上下叠的 40px 行去掉。项目行 34px，组间距 16px。10 条 × 30 + 3 行 × 34 + 两个「展示/收起」按钮 ≈ 470px，900px 视口能全放下。
- 折叠、10 条上限、「展示全部」逻辑**一行不动**（doc/50）。

## 5. 手机抽屉（修病灶 2）

- ≤860px：`.rail` 只当顶栏用（高 52px）：品牌、新对话、菜单按钮（汉堡）；导航与树全部收进抽屉。
- 抽屉：宽 280px，从左侧滑入，背后半透明遮罩；内容复用**同一棵**树的 DOM 与状态（`collapsed` / `visibleCount` / `expandedProjects`），不复制数据。
- 关闭方式三种：点遮罩、按 `Esc`、打开任意会话后自动关闭。
- 焦点：打开时聚焦抽屉第一项，关闭后回到菜单按钮；遮罩与抽屉都带 `aria-modal` / `aria-hidden` 的正确语义。
- 聊天在 ≤860px 占满剩余高度；输入区贴底并留 `env(safe-area-inset-bottom)`。

## 6. 其余三块

**页面骨架（项目 / 助手 / 团队）**

- 统一 `.page`：`max-width: 860px`、左右 32px、顶部 28px；kicker 12px 大写灰、标题 22px/600、说明 13px `--muted`。
- 卡片：白底 + 1px `--line` + 12px 圆角 + 20px 内边距，**无外阴影**；卡间距 16px。
- 按钮四型：primary（accent 实心）/ secondary（白底细边）/ ghost（透明）/ danger（白底红边红字）；高 32px、圆角 8px、13px/500。**每张卡最多一个 primary**。
- 输入：高 36px、白底、1px `--line`；focus 时 accent 边框 + 3px `--accent-soft` 环。

**对话页（修病灶 4）**

- 内容列 720px；气泡最大宽度 86%，用户右对齐、助手左对齐。
- 用户气泡：中性深墨 `--ink` 底 + 近白字（保留 doc/49 #13 的深底覆盖）；助手气泡：白卡 + 1px 边。圆角 14px，同侧下角 4px；内边距 12/16；消息间距 16px。
- 用量与「复制」从气泡内移到**气泡下方一行**（12px `--muted`，gap 8px）；用户气泡只保留「复制」。
- 空态居中：标题 20px、说明 13px、示例 chips 一行。

**细节**

- 去掉 `.app` 的米色 `radial-gradient`，背景纯 `--bg`。
- 滚动条统一 8px、滑块 `--line-strong`、轨道透明。
- `:focus-visible` 用 accent；hover 底色 `#f2f3f5`；当前项 `--accent-soft` + `--accent-ink`。
- 时间/用量用 `font-variant-numeric: tabular-nums`。

## 7. 验收

四档截图：1440×900、1024×768、700×900、390×844（Playwright 无头，脚本放 `tmp/51-UI重做/`）。判据都能脚本断言：

1. **侧栏不重叠**：900px 高、10 条会话时，`rail-foot` 的 `top ≥ tree` 的 `bottom`；`.tree` 的 `scrollHeight === clientHeight`。
2. **手机可用**：390×844 时聊天列表可视高度 ≥ 560px；抽屉能用遮罩 / `Esc` / 打开会话三种方式关闭。
3. **对比度**：正文对背景 ≥ 7:1，次要文字 ≥ 4.5:1（按相对亮度脚本算）。
4. **无横向溢出**：四档 `document.documentElement.scrollWidth === clientWidth`。
5. **一致性**：控件（有边框或实色底的按钮/输入）高度只有 28（小号）与 32（普通）两档，列表行 30（会话）与 34（项目）；圆角只出现 4 / 8 / 12 / 14 / 16 / 999 / 50%（气泡 14 与同侧下角 4 在 U5 定义）。
6. 回归：`npm run typecheck`、`npm test`；`scripts/check-master-plan.sh`。

## 8. 明确不做

- **不做深色主题与主题切换**（用户未选；以后要做得先把 token 层收完，本篇正是那一步）。
- **不引入 UI 框架/组件库**：现有是手写 CSS，换库等于把全部页面重写一遍，收益不抵风险。
- **不改交互流程与后端契约**：增删改查、事件通道、响应信封都不动。
- **不改 doc/50 的树逻辑**：折叠状态、10 条上限、「展示全部」的语义保持。
- **不做插画/动效花活**：只保留现有的 0.18s 入场与流式光标。
