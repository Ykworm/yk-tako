# 模块地图

> 性质：**结构索引**，不是方案——本文只回答「有哪些模块、每个模块落在哪些文件、干什么」。
> 最后核对：2026-11-16（代码基线 `a3ee354`）。
> 口径：**一层 = 顶层模块**（谁负责什么）；**二层 = 小模块**（落点文件 + 一句话职责）。
> 代码路径均相对 `yk-tako-eino/`；文档路径相对 `doc/`。
> 本文与 [doc/README.md](README.md)（目录页）分工：README 说「哪篇文档能施工」，本文说「代码在哪一块」。四张系统说明页在 [assets/tako-architecture.html](assets/tako-architecture.html)。

## 0. 一眼看全

| 5 | 出厂子代理规格 | `agents/` | coder / researcher 的 Markdown + YAML 规格 |
| 6 | 前端 | `web/` | Vue 3 + Vite 工作台：对话、项目、任务、文件、技能、工具与团队 |

| 8 | 文档体系 | `doc/` | 现行方案与结构索引；`log/` 是记录，`archive/` 是整代归档 |

### 0.2 规模（本次实盘点，取约数）

| 部分 | 文件与行数 |
|---|---|
| Go 非测试代码（`internal/` + `cmd/`） | 127 个文件，约 5.35 万行；其中 runengine 120 个约 5.20 万行 |
| runengine 测试 | 106 个文件，约 3.30 万行 |

规模只用于理解仓库形状，不作为质量指标。runengine 仍是单 Go 包、文件平铺；下面的小模块按职责划分，不表示真实目录层级。

## 3. 服务入口（`cmd/yktako/`）

`main.go` 是唯一可执行入口：解析工程参数，连接 PG/Redis/Redpanda，执行启动迁移，创建 store/worker/router，并启动 Task 调度、后台命令对账、记忆对账、归档清理和 HTTP 服务。

与长任务相关的参数包括 `-task-interval`、`-task-input-timeout`、`-bash-foreground-wait`、`-wait-window`、`-job-lease-*` 与 `-job-reconcile-interval`。当前代码默认 bash 前台等待窗口为 30 秒；以旗标与环境变量实际值为准。
