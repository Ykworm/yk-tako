性质：结构索引，不是方案——本文只回答「有哪些模块、每个模块落在哪些文件、干什么」。 最后核对：2026-11-16（代码基线 a3ee354）。 口径：一层 = 顶层模块（谁负责什么）；二层 = 小模块（落点文件 + 一句话职责）。 代码路径均相对 yk-tako-eino/；文档路径相对 doc/。 本文与 doc/README.md（目录页）分工：README 说「哪篇文档能施工」，本文说「代码在哪一块」。四张系统说明页在 线上架构总览（本地 doc/assets/tako-architecture.html）。

0. 一眼看全

0.1 顶层模块

# 顶层模块 位置 负责什么
1 运行引擎 internal/runengine/ HTTP、run 生命周期、工具、同步子代理、持久 Task、后台命令、记忆与项目文件
2 模型与配置 internal/config/ 厂商目录、环境变量发现、模型客户端构建、系统提示词
3 可观测装配 internal/observability/ OTel 出口、内容序列化与采集开关
4 服务入口 cmd/yktako/ 唯一入口：工程参数、依赖连接、引擎与后台对账循环起停
5 出厂子代理规格 agents/ coder / researcher 的 Markdown + YAML 规格
6 前端 web/ Vue 3 + Vite 工作台：对话、项目、任务、文件、技能、工具与团队
7 验收与运维脚本 scripts/ 开发环境、远端同步、文档检查、契约与活体验收、基准与海报导出
8 文档体系 doc/ 现行方案与结构索引；log/ 是记录，archive/ 是整代归档

3. 服务入口（cmd/yktako/）

main.go 是唯一可执行入口：解析工程参数，连接 PG/Redis/Redpanda，执行启动迁移，创建 store/worker/router，并启动 Task 调度、后台命令对账、记忆对账、归档清理和 HTTP 服务。

与长任务相关的参数包括 -task-interval、-task-input-timeout、-bash-foreground-wait、-wait-window、-job-lease-* 与 -job-reconcile-interval。当前代码默认 bash 前台等待窗口为 30 秒；以旗标与环境变量实际值为准。

4. 出厂子代理规格（agents/）

文件 职责
agents/coder.md 可改文件、写脚本、跑命令的执行规格
agents/researcher.md 调研与资料整理规格，排除 bash

规格使用 YAML frontmatter + 正文指令。同步子代理与持久 Task 可以复用执行规格，但两者的等待与恢复语义仍由 §1.5 和 §1.8 分别决定。
