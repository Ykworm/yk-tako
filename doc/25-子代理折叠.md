## 1. 要解决的事

子代理连着调工具，正文堆在自己的进程内消息列表里。压缩今天只挂在主代理上。窗口满了终稿出不来，主线程只能看到委派失败。

本拍只压子代理进程内那份消息列表。不往 `run_model_messages` 插行，不占用主 run 的 `seq=0`。runlog 里已写下的工具行不动。主线程仍只收终稿。

历史讨论见 `doc/17` §6。

## 2. 怎么压

与主 run 同一条摘要链、同一把 `-compact-window`，不另设旗标。顺序固定：

1. **估长度**（对齐 `doc/24` §5、§6）
2. **决定折不折**
3. **放行前滤上一枪 `ReasoningContent`**（对齐 `doc/24` §3）

估 / 折 / 滤细节对齐 `doc/24` 与主 midfold。滤思考与 Usage 估长度要从主 midfold 抽出共享——子代理今天只有 `callerStampMiddleware`，没有这些逻辑。

- **估**：子代理自己上一条 assistant 带着厂商账单（`PromptTokens` / `CompletionTokens`）时，长度 = 账单基线 + 那一枪可见输出 + 之后新增行；无账单（本场首呼、账单字段全为 0）时退回全量分词自测。
- **折**：只在超限时发生，留下最近一轮工具往返。写路径用现有 `extractFileOps` 钉在子代理自己的摘要末尾。摘要模型沿用主 run 的那个，不因子代理换了 `model` 再开一家。
- **滤**：必须排在估之后——减项要读思考原文，先滤只能把减项估成 0。

## 3. 错误形状

摘要失败，或不调用子代理主模型、把错误文本当作这次委派的工具结果交回去 → 父 run 保持 `complete`。

厂商以「上下文超长」拒收 → 同一形状错误文本当委派工具结果，父 run 同样 `complete`。终稿出不来是同一类事，不让一次委派把整场 run 打成 `error`。

其他错误原样上抛。

## 4. middleware 无状态

折叠挂在 ADK middleware 上，追加进子代理装配处已有的 Handlers 列表（今天已有 `callerStampMiddleware`）。

同场 run 可并行同名委派（eino ToolsNode 默认并行，tako 未改串行）。一次装配里 middleware 实例只有一份，两个 goroutine 可同时进。

禁令：实例字段里不许存任何一次调用专属的东西（计数器、上一份摘要、上一次估出的长度）。一次调用状态只走参数与 ADK 交给它的那份 `state`。

## 5. 摘要套摘要

摘要行拿不到 mh 坐标（`RunID` / `Seq` 落库才发）。它只以消息形状留在子代理进程里。第二次折叠时，上一次摘要会被当成普通历史再摘一次。

可接受。不落库补救。子代理跑完即弃，多套一层只影响终稿措辞密度。

## 6. eino #1177（台账登记）

上游 [issue #1177](https://github.com/cloudwego/eino/issues/1177)：`ChatModelAgent` 实例共享 `msgConf.cancelCtx`，并发 `Run` 复用同一实例时有 data race。v0.9.21 未修。

在 tako **当前接线**下（无 `adk.WithCancel`、停靠 Go ctx）：`cancelCtx` 多半是 nil 写 nil——有 `-race`、无功能串线。将来若用 `WithCancel`，才有 stop 串线风险。

台账如此登记。**勿按「不上互斥就不能上线」写。**

## 10. 验收

剧本：

1. 调小折叠窗口
2. 用 `bash` 造长高熵输出（例：`python3 -c 'import secrets;print(secrets.token_hex(15000))'`），**不用** `web_search`
3. 子代理连着产生两份长结果；第二次模型调用前，前一次长结果已被摘要替换

两行 dev 日志格式钉死（验收读它们）：

```text
agent fold <名字>: <前>→<后> tok; 钉 <n> 路径: <逗号连接>
agent usage <名字>: 基线 … + 可见输出 … + 新增 … = … tok，limit …
```

硬门槛：

- 主 `run_model_messages` 无子摘要行
- 终稿含两份关键信息（钉关键词判据）
- handler 零实例字段
- 超长 → 错误文本且父 `complete`
- 同名并行不串 stop（当前路径）

`web_search` 仅作旁证：密钥齐时可另投一次，看同样出现 `agent fold` 行。

## 11. 所以这解决了什么

子代理多轮工具往返时，进程内消息能在交终稿前自行压短。主线程形状不变：只收终稿，库里不出现子摘要行。估 / 折 / 滤与主 midfold 同链同窗；摘要失败与厂商上下文超长拒收都变成委派工具结果，父 run 保持 `complete`。
