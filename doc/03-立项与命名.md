## 0. 一句话

做一个属于自己的 AI 工作伙伴，对标 WorkBuddy 的"数字员工"形态：听懂自然语言，自主操作电脑
（文件、命令行、定时任务），面向个人与小微团队。做法是**生长式复刻 Octop**——每层能力自己先写，
卡住时再对照参考实现；复刻是**功能翻译，不是设计移植**（细则见《05》§翻译原则）。

## 1. 项目背景

- 目标形态参照腾讯 **WorkBuddy**：AI 原生桌面办公伙伴，不是"聊天机器人 + 一堆 tool"的拼盘。
- 复刻对象定为腾讯开源的 **Octop**：同一个问题域、可读源码、且它自己就是"应用壳 + Agent 芯"的分层结构。
- 起点是 owner 亲手写透过 pi（极简 coding agent）的 tool-call 主循环——最难理解但代码量最小的那部分已经会了。

## 2. 技术选型（终版）

| 维度 | 选型 | 说明 |
|---|---|---|
| 语言 | **Go 1.25+** | 单二进制、部署轻；与 Eino / WeKnora 生态同语言 |
| Agent 内核 | **[Eino](https://github.com/cloudwego/eino)**（字节 CloudWeGo，主线用 v0.9.21） | Chain/Graph/Workflow 编排 + ADK（ChatModelAgent / middleware / prebuilt） |
| 功能参照物 | **Octop**（腾讯开源，本机 `ref-agent/Octop`） | 只回答"要什么"：功能规格、行为对照、卡住时的参考答案 |
| 架构 / 类库参考 | **WeKnora**（腾讯开源，本机 `ref-agent/WeKnora`） | Eino 没有的类库（记忆、RAG、MCP、IM、沙箱等）照它的 Go 实现来 |

> 只保留 Go/Eino 一条主线：TypeScript 实现（LangGraph.js + deepagents）在 2026-09-24 定案后已删除，
> 反转过程见《04-技术路线》§反转记。`maf/`（Microsoft Agent Framework 对照）保留为冻结存档，不再推进。

### 2.1 为什么是 Eino（一句话版本）

不是"Eino 比 LangGraph.js 强"，而是两件更硬的事：

1. **系统拓扑**：目标形态是本地单二进制 Agent，Go 一路到底比"Go 后端 + Node Agent"少一种运行时；
2. **对"确定性"的正式答案**：LangGraph 系只有 middleware 一层可做文章，"规划与执行的时序"只能用软钩子模拟；
   Eino 把分界写死（Graph 管确定性、Agent 管自主性），要硬保证时直接编图。
   调研全文见《08-Eino规划机制调研》。

### 2.2 WeKnora 可借鉴的架构要点

- **技术栈**：Go + Gin + PostgreSQL/pgvector + Redis（asynq 任务队列）+ MCP + 沙箱（Docker/E2B）+ Vue 前端
- **分层风格**：标准 DDD 风格 `internal/` 目录

  ```text
  internal/
    agent/          # Agent 核心（ReAct、工具编排）
    application/    # 应用服务层
    handler/        # HTTP Handler
    types/ config/  # 领域类型、配置
    mcp/ sandbox/   # MCP 集成、代码执行沙箱
    event/ router/ middleware/ logger/ tracing/
  ```

- **能力参考**：RAG 问答、ReAct Agent、MCP 工具、技能目录（Skill Catalog）、长时记忆、知识库管理、多渠道 IM 接入

我们当前只借它的**工程分层与类库选型**，不借产品形态：yk-tako 先长 Agent 芯，壳（Web/IM/定时）在后面层级。

## 3. 命名

### 3.1 候选与演进

| 名字 | 寓意 | 结果 |
|---|---|---|
| Einora | Eino × WeKnora 合体，致敬两个技术血缘 | ❌ 随全栈 TS 路线作废（后被 Eino 复活，仍弃用） |
| OctoGo / Goctop | Octop（Octopus）章鱼词根 | ❌ 随路线反转作废 |
| DoWork / Doworker | "干活的人"，呼应数字员工 | ❌ 落选 |
| 搭子 / DaZi | 中文"工作搭子" | ❌ 传播性好但偏口语 |
| Pito | pi × octopus 合成 | ❌ 故事性强，最终惜败 |
| **Tako** | 日语"章鱼"——八腕并行=多工具/子代理，2/3 神经元在腕上=智能分布在中间件层 | ✅ **定案** |

**2026-09-23 定案：`yk-tako`**（`yk-` 个人前缀 + Tako）。电话测试过关：两音节开元音、无歧义、
中文语境无坏联想，全球可读。目录已按此重命名。

### 3.2 命名注意事项（备份忘）

1. 避开腾讯系商标：`WorkBuddy`、`CodeBuddy` 均已注册，名字里不要出现 `Buddy` + `Work/Code` 组合。
2. 对外开源前做三连检查：GitHub 仓库名、Docker Hub / npm / Go module 路径、域名可用性。
