## 1. 项目背景

目标是模仿腾讯 **WorkBuddy**（AI 原生桌面办公伙伴：听懂自然语言、自主操作电脑——文件/应用/截图/定时任务，面向个人与小微团队的"数字员工"），做一个属于自己的 AI 工作伙伴。

## 2. 技术选型

| 维度 | 选型 | 说明 |
|---|---|---|
| Agent 编排内核 | **Eino**（字节 CloudWeGo） | Go 语言 LLM 应用框架，提供 Chain/Graph 编排、ReAct Agent、MCP 集成 |
| 架构参考 | **WeKnora**（腾讯开源） | 源码位于 `/Users/yuweikang/dev/ykcode/WeKnora`，借鉴其工程架构与分层 |
| 后端语言 | Go 1.26+ | 与 WeKnora / Eino 生态一致 |

### WeKnora 可借鉴的架构要点

- **技术栈**：Go + Gin + PostgreSQL/pgvector + Redis（asynq 任务队列）+ MCP + 沙箱（Docker/E2B）+ Vue 前端
- **分层风格**：标准 DDD 风格 `internal/` 目录：

  ```
  internal/
    agent/          # Agent 核心（ReAct、工具编排）
    application/    # 应用服务层
    handler/        # HTTP Handler
    types/          # 领域类型
    config/         # 配置
    mcp/            # MCP 集成
    sandbox/        # 代码执行沙箱
    event/          # 事件总线
    router/ middleware/ logger/ tracing/ ...
  ```

- **能力参考**：RAG 问答、ReAct Agent、MCP 工具、技能目录（Skill Catalog）、长时记忆、知识库管理、多渠道 IM 接入
