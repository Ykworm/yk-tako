# 流式枢纽人工验收

设计稿第 8 节的浏览器部分。机器用例已经在 `go test -race ./...` 里，这里只记人手要看的四条。
服务：`cd yk-tako-eino && go run ./cmd/yktako -web 127.0.0.1:8765`。

- [ ] **断网或刷新**：一轮进行中刷新页面。刷新前已经出现的内容还在，后面新出现的帧接在后面，不从头重复刷一遍。
- [ ] **停止**：点停止。这一轮停住，日志里只有一次「已停止」。接着再发一句话，能开新的一轮。
- [ ] **两个标签页**：一轮进行中打开第二个标签，会话 id 相同（localStorage）。第二个标签能看到同一场 run 的后续帧。
- [ ] **REPL**：不带 `-web` 再跑一次多步任务。终端格式与以前一致；有参数的工具调用在名字后带截断后的参数。当前目录不出现被 REPL 写过的 `yktako-webui.db`。
